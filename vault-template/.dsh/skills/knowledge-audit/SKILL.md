# 知识巡

## 巡检标准

执行 `知识巡` 时，先运行：

```powershell
python ".agents/scripts/knowledge_router.py" --audit
```

然后检查：

- Inbox 待处理笔记。
- 低置信度分类。
- 没有任何链接的候选孤立笔记。
- 已到 `review_after` 的笔记。
- 未完成任务。
- 重复、过时或可升级为 Evergreen 的内容。
- 缺少 `description` 或 Skill 式检索属性的知识卡片。
- 缺少 `_Index.md` 的知识主题目录。
- 根目录知识路由索引与实际目录不一致的条目。
- 知识收文档转换与知识理模式规则执行情况：
  - 文件转换来源笔记是否记录源文件、格式、大小、修改时间、SHA-256 和转换方式。
  - Excel、CSV、TSV 是否完整保留工作表或行列范围，没有静默抽样、聚合或去重。
  - PDF、Word、PowerPoint 图文混排是否按用户选择使用原图附件或 OCR，图片引用是否存在，OCR 失败是否明确标记。
  - 知识理的精简/保真模式是否按用户选择执行；若仍有重要未处理主题，不应过早归档来源笔记。
  - 图文资料提炼出的卡片是否在对应文字说明之后嵌入或链接相关图片、截图、PDF 或图表。
  - `07_Attachments/` 中最近新增附件是否至少被一篇 Markdown 来源笔记或知识卡片引用。

巡检只生成报告和建议；未经用户确认，不删除、合并或批量改写笔记。
