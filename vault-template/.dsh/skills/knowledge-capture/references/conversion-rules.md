# 文档转换完整性规则

仅在 `knowledge-capture` 实际处理对应格式时读取相关章节。

## 通用整理

- 按源文件阅读顺序组织，不按主题重新拆卡。
- 保留标题、正文、列表、表格、公式文本、代码、脚注/尾注、题注、页码或幻灯片编号、讲者备注和图片位置。
- 允许合并同一段落的软换行、清除空白页与纯布局空行、规范 Markdown 转义。
- 重复页眉页脚只有在确认内容完全一致时可折叠，并在转换说明中记录；否则保留。
- 原文件始终是版式和不可转换对象的最终依据。Markdown 必须列出已知偏差，不能声称无损。

## Excel / CSV / TSV

- 默认转换全部工作表和已用区域，不抽样、不聚合、不去重。
- 保留工作表顺序、行列顺序、空值、公式、可取得的缓存值、错误值和合并区域。
- 在每个工作表开头记录可见性、冻结窗格、筛选范围、隐藏行列、批注和合并区域；这些信息不必伪装成表格内容。
- 超宽或超长表格可以按工作表拆分为多个 Markdown 文件，但必须有一个 Inbox 索引文档，且能按原行列顺序恢复。
- 宏、图表、数据验证、条件格式和外部连接不能可靠转成 Markdown 时，列入转换说明；`.xlsm` 不得执行宏。

## Word

- 按文档块顺序保留段落、标题、列表、表格和内嵌图片。
- 处理页眉、页脚、脚注、尾注和批注；无法确定锚点时集中放在对应章节末尾并标出来源部件。
- 原图模式把图片紧跟其锚点段落或表格单元格；OCR 模式把识别文本放在同一位置并标记 `[图片 OCR]`。
- 文本框、SmartArt、公式对象、修订记录或域代码无法完整还原时明确列出，不得静默丢弃。

## PowerPoint

- 保留幻灯片顺序；每页使用二级标题，并按从上到下、从左到右的视觉顺序整理对象。
- 保留标题、正文、列表、表格、图片、图表说明和讲者备注。
- 原图模式在对象对应位置嵌入；OCR 模式在对象位置插入识别文字。
- 动画、切换、视频、音频、嵌入对象和母版视觉效果无法转成 Markdown 时列入转换说明。

## PDF

- 保留页码边界，优先按页面文本块坐标恢复阅读顺序。
- 原图模式提取页面中的图片并插入对应文本块位置；扫描页无法分离图文时可把整页渲染为图片。
- OCR 模式对扫描页或图片块识别，按页面与坐标插回；保留 `[第 N 页·图片 OCR]` 标签。
- 多栏、复杂表格、公式、矢量图和字符映射异常必须列入转换说明。OCR 结果不是法律或审计意义上的原件。

## OCR 质量

- 默认语言为 `chi_sim+eng`，可根据文档语言调整。
- 保留段落和换行，不自行补全无法识别的字词。
- 空结果、乱码或明显低置信时写 `[OCR 未能可靠识别]`，并报告对应页/图片编号。
- 涉及金额、账号、日期、公式、专有名词或表格时，应重点核对；无法核对就标记不确定。
