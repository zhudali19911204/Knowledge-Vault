# 知识收

执行前先完整遵守：

- 根目录 `AGENTS.md` 中“触发指令：知识收”与安全规则。
- `05_Skills/0501_Knowledge Management/知识路由规则.md` 中对应模式的完整 SOP 和完成前自检。

工作流：

1. 从用户指令判断来源是当前对话，还是用户明确指定的文件或目录。
2. 如果用户没有明确写出 `精简` 或 `保真`，先询问模式；在得到选择前，不读取、复制、解析或写入资料。
3. 表格资料默认使用保真模式；用户明确要求精简时，必须保留原附件，或记录源路径、大小、最后修改时间和 SHA-256，并声明 Markdown 不是原表的完整替代。
4. 外部来源只读。需要转换或规避文件锁时使用临时副本，并在完成后清理临时副本。
5. 只在 `01_Inbox/` 创建 `type: source`、`status: inbox`、`retrieval_priority: low` 的来源笔记。
6. 需要保留的非 Markdown 附件进入 `07_Attachments/` 的合规编号目录，并从来源笔记链接或嵌入。
7. 收集阶段不创建 `knowledge-skill` 卡片，不路由来源笔记，不改写用户未指定的资料。
8. 检查并排除密码、令牌、登录凭据和未经授权的敏感信息。
9. 按 SOP 自检，并实际确认来源笔记与已复制附件存在后再报告完成。

无参数收集当前对话时，文件名使用 `01_Inbox/YYYY-MM-DD HHmm - 对话主题.md`。文件名不得包含 `\ / : * ? " < > |`。
