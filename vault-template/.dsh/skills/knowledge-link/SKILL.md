# 知识联

遵守根目录 `AGENTS.md` 和 `05_Skills/0501_Knowledge Management/知识路由规则.md` 的关联标准。

1. 确定用户指定笔记；未指定时检查最近新增的知识笔记，避免无差别读取整个 Vault。
2. 对 `knowledge-skill` 检查并修正 `description`、`use_when`、`do_not_use_when`、`match_questions`、`triggers` 和 `aliases` 的范围。
3. 只基于真实的概念、方法、项目、来源、版本或上下游关系补充链接；关键词相同但没有理解价值时不链接。
4. 需要建立双向关系时，同时更新相关文档的 `related` 或正文链接，且保持每篇笔记只有一个主目录。
5. 更新所属 `_Index.md` 的文档路由表、本目录文档列表和必要的相关知识包链接。
6. 更新根目录 `知识路由索引.md`，确保路由描述、适用边界与实际目录一致。
7. 发现疑似重复、冲突或应合并的笔记时先报告，不删除、不合并、不覆盖。
8. 完成前检查链接目标存在、索引一致、来源追溯未断裂，并报告实际改动文件。
